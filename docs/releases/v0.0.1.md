# WOW Sidecar v0.0.1 release runbook

This runbook releases the Go Sidecar image. The Python compatibility image and
its operator state are separate products and must not be replaced as part of
this release.

## Release gates

1. Merge the reviewed duplicate-JSON-key hardening and release-workflow changes
   into public `main`. Keep Agent Dispatch provider dispatch disabled; this
   release does not authorize work execution.
2. On the exact merged `main` commit, require the public qualification workflow
   to pass: dependency/public-safety checks, Go tests and vet, static amd64 and
   arm64 builds, two-platform OCI qualification, and receipt-contract checks.
3. Dispatch `WOW Sidecar Go multi-arch publication` from `main` with
   `qualify_only=true` and the exact SHA and version. Require qualification to
   pass and confirm that publication is skipped. Then dispatch it again with
   `qualify_only=false` and:
   - `expected_sha`: the exact 40-character merged commit SHA;
   - `release_version`: `0.0.1` (without a `v` prefix);
   - `confirm`: `publish-go-multiarch-v0.0.1-exact`.
4. Require publication to create the previously unused immutable image tag
   `ghcr.io/sempersupra/wow-sidecar:v0.0.1`, verify the exact source SHA and
   version labels, pass native amd64 and arm64 runtime/restart checks, and emit
   the durable digest receipt. If the tag already exists, stop and reconcile;
   never retry by overwriting it.
5. Review the receipt and deployment target, backup, migration, and rollback
   evidence. Deploy only after those checks are independently satisfied. Keep
   the current host image and state intact until the replacement is live and
   rollback is verified.

The workflow publishes and qualifies an image; it does not deploy to the host.
The release remains incomplete until deployment evidence is recorded.
